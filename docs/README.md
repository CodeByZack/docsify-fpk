# 📚 Docsify 文档站

欢迎使用！这是一个基于 [docsify](https://docsify.js.org/) 的轻量静态文档站，跑在飞牛 fnOS 上。

## 怎么用

**往文档目录放 `.md` 文件，刷新页面即可发布。**

- **主文档目录**：安装/配置时填写的目录（留空 = 应用共享目录）
- **应用共享目录**：始终生效——往共享目录拖 `.md` 也会出现在侧边栏
- 放进去的每个 `.md` 会自动出现在左侧边栏（共享目录的文档在「应用共享目录」分组下）
- 支持子目录，docsify 会自动生成目录树

> 文档目录里**只需要放 .md 文档**——`index.html`、`assets/` 等引擎文件由应用统一提供
> （从应用内置模板伺服，文档目录中的同名文件不生效）。

## 脑图渲染

内置 markmap：在 md 里写原生 HTML 块即可把 markdown 层级渲染成可交互思维导图，
写法和配置见 [markmap-demo](/markmap-demo.md)。

## 常见问题

**共享目录和配置的文档目录有什么区别？**
两个都是文档源。共享目录（`/var/apps/docsify-fpk/shares/docsify-docs`）里的文档在
`/shared/` 路径下，侧边栏自动分组展示；主文档目录在根路径。

**外部目录（如 /vol1/1000/docs）读不到？**
到「应用中心 → 本应用 → 设置 → 目录授权」添加该目录的访问权限，再在配置中确认文档目录路径。

**怎么改端口？**
默认 8666，可在应用配置中修改。桌面图标固定指向 8666，端口不同时 8666 空闲会自动跳转。
